После обновления источника проверьте в превью датасета:

- в пользовательском датасете нет размножения строк после JOIN;
- `segment` заполнен для каждой строки;

### Датасет «Пользователи»

| Название | Формула | Формат |
|---|---|---|
| CR Algo | `FDIV_SAFE(SUM([algo_completed_listens]), SUM([algo_listening]))` | Процент, 1 знак |
| CR Organic | `FDIV_SAFE(SUM([organic_completed_listens]), SUM([organic_listening]))` | Процент, 1 знак |
| Skip Rate Algo | `FDIV_SAFE(SUM([algo_short_listens]), SUM([algo_listening]))` | Процент, 1 знак |
| Skip Rate Organic | `FDIV_SAFE(SUM([organic_short_listens]), SUM([organic_listening]))` | Процент, 1 знак |
| Conv Algo | `FDIV_SAFE(SUM([algo_likes]), SUM([algo_listening]))` | Процент, 2 знака |
| Conv Organic | `FDIV_SAFE(SUM([organic_likes]), SUM([organic_listening]))` | Процент, 2 знака |
| Avg Unique Algo | `FDIV_SAFE(SUM([algo_unique_items]), COUNTD([uid]))` | Число, 1 знак |
| Avg Unique Organic | `FDIV_SAFE(SUM([organic_unique_items]), COUNTD([uid]))` | Число, 1 знак |
| Algo Like Cancel Rate | `FDIV_SAFE(SUM([algo_unlikes]), SUM([algo_likes]) + SUM([algo_unlikes]))` | Процент, 2 знака |
| Segment Order | `CASE [segment] WHEN "Cold" THEN 1 WHEN "Passive" THEN 2 WHEN "Mixed" THEN 3 WHEN "Explorer" THEN 4 ELSE 5 END` | Целое |

`Avg Unique *` по формуле ТЗ корректно интерпретируется при выборе одного
`time_period`. Для диапазона из нескольких периодов знаменатель считает
уникального пользователя один раз, а числитель суммирует его дневные значения.
Поэтому на чарте разнообразия добавьте обязательный селектор одного периода
или замените формулу на `AVG([algo_unique_items])` / `AVG([organic_unique_items])`,
если нужен средний пользователь-период за диапазон.

## 5. Приёмка

1. Выберите один период и вручную сверьте каждую формулу с суммами исходных
   колонок в превью датасета.
2. Проверьте, что фильтр `segment` влияет на чарты 1–3, но не размножает
   пользовательские строки.
3. Проверьте нулевые знаменатели: чарт должен показывать пропуск, а не `0%`
   и не ошибку.
4. Для тезиса о парадоксе Симпсона зафиксируйте общий `Conv Algo` и значения
   по каждому сегменту вместе с долей алгоритмических прослушиваний сегмента.
5. Не утверждайте причинность по описательному графику: формулируйте вывод как
   подтверждённую/неподтверждённую гипотезу и дополняйте экспериментом или
   квазиэкспериментальным анализом при необходимости.
